## 3. 已选定方案与取舍

1. **纯 NumPy 向量化解析传播（采用）**：与冻结的二体圆轨道一致，快、可重现、无新外部模型。
2. **逐卫星 Python 循环**：更直观，但后续全时间序列产生速度较差，且更容易产生序号错位。
3. **Skyfield/SGP4**：天文模型更完整，但与“无真实 TLE、解析二体圆轨道”的契约冲突。

## 4. 数学与坐标约定

### 4.1 Walker 初始化

```text
sat_id = sat_p{plane:02d}_s{slot:02d}
RAAN_p = normalize_deg(p * raan_spacing_deg)
phase_p,s = normalize_deg(s * 360 / satellites_per_plane
                           + p * 360 * phasing / total_satellites)
```

卫星顺序固定为 `(plane, slot)` 升序，不得依赖 dict/set 迭代顺序。

### 4.2 解析圆轨道

对秒偏移 `t_s >= 0`：

```text
u(t) = phase_rad + mean_motion_rad_s * t_s
r_orb = [r*cos(u), r*sin(u), 0]
r_eci = Rz(RAAN) @ Rx(inclination) @ r_orb
```

轨道半径和平均运动角速度必须使用 `SimulationContract` 已有派生属性，不得再写数值常量。

### 4.3 固定 epoch GMST 与 ECI→ECEF 约定

第三阶段采用 UTC epoch 计算一次 GMST 初始角，之后按第二阶段已冻结的 `earth.rotation_rad_s` 推进。不调用系统当前时间，不依赖 Skyfield、TLE 或网络服务。

先将 `epoch_utc` 解析为带 UTC 时区的 datetime，由 Unix 秒数计算 Julian Date：

```text
JD = unix_seconds / 86400 + 2440587.5
T = (JD - 2451545.0) / 36525
GMST_epoch_deg = normalize_deg(
    280.46061837
    + 360.98564736629 * (JD - 2451545.0)
    + 0.000387933 * T^2
    - T^3 / 38710000
)
```

仿真时间推进与坐标旋转：

```text
theta(t) = normalize_rad(radians(GMST_epoch_deg) + earth_rotation_rad_s * t_s)
r_ecef = Rz(-theta(t)) @ r_eci
longitude = atan2(y, x), normalized to [-180, 180)
latitude = atan2(z, hypot(x, y))
```

对冻结 epoch `2025-01-01T00:00:00Z`，参考值固定为 `JD=2460676.5`、`GMST_epoch_deg=100.89956789370626`。该公式用于理想化球形地球仿真中的经度对齐，不声称达到 IERS 地球定向或高精度轨道测定水平。

### 4.4 地球遮挡

对卫星端点 `a,b`，`d=b-a`：

```text
tau = clip(-dot(a,d) / dot(d,d), 0, 1)
closest = a + tau*d
earth_clear = norm(closest) > earth_radius_km
```

必须使用严格大于；等于地球半径视为被遮挡。

### 4.5 地面仰角

```text
ground = R * [cos(lat)cos(lon), cos(lat)sin(lon), sin(lat)]
los = satellite_ecef - ground
elevation = asin(dot(los/|los|, ground/R))
visible = elevation_deg >= minimum_elevation_deg
```

选取仰角最大者；差值在 `1e-12 degree` 内时按 `sat_id` 字典序。无可见卫星时 `selected_sat_id=None` 且 `access_backlog=True`。

### 5.2 数据类型

```python
@dataclass(frozen=True)
class Satellite:
    sat_id: str
    plane: int
    slot: int
    raan_deg: float
    phase_deg: float

@dataclass(frozen=True)
class PositionSnapshot:
    time_s: int
    sat_ids: tuple[str, ...]
    eci_km: np.ndarray       # shape (66, 3), float64
    ecef_km: np.ndarray      # shape (66, 3), float64
    latitude_deg: np.ndarray # shape (66,)
    longitude_deg: np.ndarray# shape (66,)

@dataclass(frozen=True, order=True)
class DirectedLink:
    src: str
    dst: str
    distance_km: float
    propagation_delay_s: float
    link_type: str           # intra_plane | inter_plane

@dataclass(frozen=True)
class TopologySnapshot:
    time_s: int
    nodes: tuple[str, ...]
    directed_links: tuple[DirectedLink, ...]

@dataclass(frozen=True)
class AccessAssignment:
    region_id: str
    visible_count: int
    selected_sat_id: str | None
    selected_elevation_deg: float | None
    access_backlog: bool
```

Python 3.9 不支持 `str | None`，实际代码必须使用 `Optional[str]` 和 `Optional[float]`。上述注释是语义契约，Codex 不得直接复制为不兼容语法。
`PositionSnapshot` 创建后必须将四个 NumPy 数组设为 `writeable=False`，避免冻结 dataclass 内部数组仍被就地修改。

## 6. 拓扑详细规则

### 6.1 轨内链路

- 每星生成 `(slot-1) mod 11` 和 `(slot+1) mod 11` 两个候选；
- 先生成无向规范键 `(min_id,max_id)` 去重，再展开为两条有向边；
- 同时检查地球遮挡和 `max_distance_km`；
- 若固定轨内候选失败，不搜索替代邻居，审计报告必须报错。

### 6.2 跨轨链路

- 只处理平面对 `(0,1),(1,2),(2,3),(3,4),(4,5)`；
- 任一端 `abs(latitude)>70` 的卫星不参与当次匹配；
- 每个卫星对相邻平面中所有候选按 `(distance_km, sat_id)` 取最小；
- `a` 选择 `b` 且 `b` 也选择 `a` 时才建链；
- 先用地球遮挡和最大距离过滤合法候选对，再在合法候选中做互选；
- 无 Walker Star 接缝 `(5,0)`，节点度允许小于 4，但不得大于 4。

### 6.3 计划与运行拓扑

- `build_planned_topology` 只使用轨道决定信息；
- `build_operational_topology` 仅删除外部给定的无向故障边的两个方向；
- 默认空故障集时 `G_op == G_orb`；
- 故障集包含不存在的边时报 `ValueError`，避免隐藏上游错误；
- 本阶段不生成随机故障集。

## 10. 失败分支

| 失败 | 强制处理 |
|---|---|
| 第二阶段验证器不通过 | 停止，不得在仿真器中覆盖契约 |
| 轨道半径不守恒 | 回到 Task 2 检查旋转矩阵和 degree/radian |
| GMST 参考值不符 | 回到 Task 3 检查 UTC 解析、Unix 秒、Julian Date 和 degree/radian，不修改参考容差 |
| ECI/ECEF 方向错误 | 回到 Task 3，用冻结 epoch GMST 和单轴人工向量定位 |
| 轨内邻居超过 5000 km | 输出证据并停止，回第二阶段审查距离阈值 |
| 节点度大于 4 或出现接缝边 | 判定匹配逻辑错误，第三阶段不通过 |
| 长时间覆盖空洞 | 保留审计结果，回第二阶段审查仰角/星座假设，不伪造覆盖 |
| 重复运行哈希不同 | 排查 set/dict 顺序、时间戳、绝对路径和非确定性并行化 |
| 资源超限 | 分块计算覆盖矩阵，不降低 980 区域或 10 s 轨道更新粒度 |
