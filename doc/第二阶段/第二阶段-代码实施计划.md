# 第二阶段研究与仿真契约实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` and `superpowers:test-driven-development` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已确认的研究与仿真参数固化为可由 Schema 和 Python 交叉验证的唯一契约。

**Architecture:** YAML 是参数真值源，JSON Schema 拦截字段和类型错误，不可变 dataclass 暴露派生量，契约对验证器检查跨文件约束。CLI 将结果生成人可读审计和机器可读 manifest。

**Tech Stack:** Python 3.9, PyYAML, jsonschema 4.23.0, dataclasses, unittest.
